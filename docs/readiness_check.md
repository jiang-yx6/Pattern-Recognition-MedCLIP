## 需要团队统一理解的限制

- 77 token 截断会丢弃部分原文，HTML 仍显示全文。train/val/test 分别截断 1385/4000、169/500、167/500。后续保持输入规则一致，解释截断导致的检索误例。
- 报告文本重复有 466 行（首条之外）；跨 split 也有相同文本。这不是患者交叉，但按同检查唯一正例评估时会出现语义相同而配对 ID 不同的候选。
- 训练集中 2456 条、验证集 331 条、测试集 309 条的五类 mask 全为 0。这些仍可参与配对学习，不能把未知标签当作已知阴性。
- 自动源文件核查及缩略图查看不能确认所有细微临床描述，也没有在本次检查中验证每位团队成员的 PhysioNet 资格。
- 当前依赖组合在本机验证通过，未在另一台全新机器重新下载和安装全部包；GitHub 工作流尚需上传后实际运行。未创建远程仓库、提交或推送。
- 源码提交检查用于当前文件边界、语法和常见泄漏模式，不是 Git 历史清理器，也不是完整的凭据/医疗数据检测系统。
